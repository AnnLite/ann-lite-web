# Code of Conduct

Ann Lite is a Christian platform built to serve people with respect and
compassion. That standard applies to how we build it, too.

## Our standard

- Treat every contributor, maintainer, and user with respect, regardless of
  denomination, background, nationality, or technical experience level.
- No harassment, discrimination, or personal attacks in issues, pull
  requests, code review, or any project space.
- Assume good faith; disagree about code and ideas, not people.
- Protect the dignity of the vulnerable people this project ultimately
  serves — never suggest or merge content that exposes personal data about
  children, orphans, or vulnerable adults.

## Reporting

Report unacceptable behavior privately to the maintainers listed in
`SECURITY.md`'s contact channel. Reports are handled confidentially.

## Enforcement

Maintainers may edit, remove, or reject contributions that don't follow
this Code of Conduct, and may temporarily or permanently ban contributors
for repeated or severe violations.

This document is adapted in spirit from the Contributor Covenant.
